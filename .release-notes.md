## What's Changed

### Bug Fixes
- **Log writer**: switched to append mode with size-based rotation (keeps the tail beyond 1 MB). Previously every entry re-read and re-wrote the whole log file (O(n) per line), which could snowball if a sensor error repeated on every frame on a long-running instance.
- **Display identification**: the serial-number fallback ("AD...") is no longer trusted blindly. Candidate ports now must pass a protocol handshake - a firmware-version query must return exactly 19 bytes echoing the command. Ports that fail are closed and skipped, so binary WeAct commands can no longer be sent to an unrelated device.
- **Single instance guard**: a second launch (manual + autostart collision) now exits cleanly after logging, instead of two instances fighting over the serial port. The pid file is actually checked now (previously written but never read).

### Notes
- No changes to rendering or data sources; update rate is still limited by the 115200 baud full-frame transfer (~3.5 s per frame), as documented.
